# thegameswhoise

A responsive, galaxy-themed landing page and game library with 40 empty slots, ready for games to be added later.

## Run it

Open `index.html` in a browser. It is a static site with no build step or dependencies.

## Add games later

The 40 starter cards are generated from the `games` array in the script near the bottom of `index.html`. Replace the placeholder entries with your game data and update the card rendering to show the title, artwork, and launch link. The search and slot sorting controls are already wired up.
